# UDS 与内部命令

承载先用 TCP。QEMU 上 ca-ota 监听 27100。`scripts/diag_tester.sh` 发送刷写成功路径。32 位客户机加参数 `aarch32`。服务号按 ISO 14229。

| 服务 | 作用 | TA |
| --- | --- | --- |
| `0x10 02` | 进入编程会话 | 无，只在 CA |
| `0x27` | 先取种子，再交签名 | `0x1002`，`0x1003` |
| `0x22` | 读 KVN、SVN、根哈希指纹 | `0x1001` |
| `0x31 F000` | 更新二级公钥 | `0x1004` |
| `0x34` | 开始下载 | 随后先送镜像头 `0x1010` |
| `0x36` | 数据块 | `0x1011` |
| `0x37` | 结束传输 | 然后 `0x1012` |
| `0x31 F002` | 激活 | `0x1013` |

`0x36` 的 `blockSequenceCounter` 从 `0x01` 起，到 `0xFF` 后绕回 `0x00`。重复上一序号是重传。跳号返回 NRC `0x24`。

镜像头 `FIMG` 在数据块之前，由当前二级私钥签名。头内包含 SVN、KVN、总长度、整包 SHA-256、块大小、块数和每块 SHA-256。Key Manifest `FKM1` 由根私钥签名，携带新的二级公钥和更大的 KVN。
